Como começar

  1. Extraia todo o ZIP e abra admin.html.
  2. Na criação da competição, informe o nome e escolha 1, 2 ou 3 quadras. O intervalo mínimo é opcional.
  3. Crie uma categoria e informe a quantidade de duplas.
  4. Cadastre os dois atletas de cada dupla ou cole uma lista, com uma dupla por linha no formato Atleta 1 / Atleta 2.
  5. Use Sortear e abrir chaveamento. O sorteio é automático e você já entra na tabela.
  6. Nas quadras, use Escolher jogo para decidir qual partida iniciar. Você também pode gerenciar qualquer jogo pronto pela tabela.
  7. No fim da partida, registre o placar ou selecione W.O. e a dupla vencedora.
  8. Abra index.html para acompanhar os resultados.

Jogos e cruzamentos

A chave dos vencedores fica à esquerda e a dos perdedores à direita. No celular, alterne entre Vencedores, Finais e Perdedores.

Os cruzamentos da repescagem são definidos ao terminar as etapas anteriores. O sistema consulta os adversários já enfrentados e não libera reencontros antes das semifinais. As partidas de uma etapa permanecem estáveis enquanto são disputadas.

Vencedores das semifinais disputam a final. Perdedores disputam terceiro lugar. A final é única.

O W.O. registra a vitória da dupla selecionada e uma derrota para a adversária, sem criar um placar numérico. A classificação segue o mesmo avanço dos demais resultados.

A escolha de jogos é manual. O sistema bloqueia uma quadra ocupada e a participação simultânea do mesmo atleta em jogos diferentes. Para identificar atletas entre categorias, use o mesmo nome completo para a mesma pessoa e diferencie homônimos.

Alterar e zerar

Zerar categoria: apaga sorteio, jogos e resultados da categoria. Mantém seu nome e os atletas.

Zerar competição: apaga todas as categorias e retorna à tela de criação.

As duas ações pedem a palavra ZERAR. Antes de corrigir um resultado, o painel informa quais jogos posteriores serão apagados. Se houver dependentes em quadra, reabra-os primeiro.

Use Exportar backup para guardar a competição e Importar backup para restaurá-la. Os backups desta versão usam o formato V3 e são compatíveis com a versão 3 anterior.

Teste em duas abas

Esta versão ainda guarda os dados no navegador e não tem senha. Outros aparelhos não recebem as atualizações automaticamente. Para compartilhar os resultados entre duas abas do mesmo navegador, sirva os arquivos por HTTP, na mesma origem.

Se já tiver Python instalado, abra um terminal nesta pasta:

python -m http.server 8000 --bind 127.0.0.1

No Windows, pode usar py no lugar de python. Abra:

http://localhost:8000/admin.html
http://localhost:8000/index.html

Também funciona com o Live Server do VS Code ou hospedagem estática. O conteúdo do ZIP pode ser colocado na raiz de um projeto do Cloudflare Pages, sem build.

Arquivos

admin.html: criação e organização. inscricoes.html: cadastro das duplas. chaveamento.html: tabela e gerenciamento. index.html: acompanhamento.

styles.css, routing.js, app.js, engine.js e templates.js contêm o visual e a lógica. A pasta assets contém as logos da Roteirizze.
